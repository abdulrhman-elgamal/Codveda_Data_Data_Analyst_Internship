# Level 1: Data Cleaning & Exploratory Data Analysis (EDA)

This section focuses on raw data ingestion, handling missing values, outlier detection, data transformation, and deep exploratory data analysis to uncover initial insights.

## Tasks Covered:
1. **Task 1: Data Cleaning (`Level_1_Task_1_Cleaning.ipynb`)**
   - Handling null values and duplicates.
   - Data type casting and string standardization.
   - Preparing datasets like `4) house Prediction Data Set.csv` and telecom datasets for analysis.

2. **Task 2: EDA & Visualization (`Level_1_Task_2_EDA_Visualization.ipynb`)**
   - Univariate and bivariate analysis.
   - Correlation heatmaps using Seaborn.
   - Identifying distributions and key data trends.
