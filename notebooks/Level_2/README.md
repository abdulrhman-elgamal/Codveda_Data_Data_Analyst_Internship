# Level 2: Regression & Unsupervised Clustering Models

This section covers predictive modeling for continuous variables and unsupervised pattern recognition (clustering) to segment data points.

## Tasks Covered:
1. **Task 1: Regression Analysis (`Level_2_Task_1_Regression.ipynb`)**
   - Building and evaluating Linear & Multiple Regression models.
   - Feature selection and metric evaluation ($R^2$, RMSE, MAE).

2. **Task 3: Clustering (`Level_2_Task_3_Clustering.ipynb`)**
   - Applying K-Means and hierarchical clustering algorithms.
   - Finding optimal clusters using the Elbow Method and Silhouette Score.
   - Customer/Data segmentation insights.
